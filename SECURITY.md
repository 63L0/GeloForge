# Security Policy and Boundary Disclosure

## Enforced Technical Controls vs. Documented-Only Safeguards

This repository clearly separates controls that are **technically enforced by code today** from controls that are **documented policy targets** for future phases:

### Technically Enforced Controls (v0.3.0)
- **Bootstrap Path, Traversal & Symlink Defense ([core/path-safety.mjs](./core/path-safety.mjs)):** Rejects relative `..` traversal segments, UNC/network paths, illegal characters, Windows reserved device names (`CON`, `PRN`, `AUX`, `NUL`, `COM1`–`COM9`, `LPT1`–`LPT9`), trailing dots/spaces, filesystem roots, sensitive output filenames (`.env*`, `secrets/`, keys, `credentials.json`), symlink/NTFS junction ancestors (while permitting OS-owned macOS `/tmp`/`/var` root links cleanly during realpath checks), and destinations inside protected harness directories.
- **Overwrite Refusal & Transactional Writes ([scripts/bootstrap-project.mjs](./scripts/bootstrap-project.mjs), [core/path-safety.mjs](./core/path-safety.mjs)):** Project initialization refuses existing destinations and stages inside a temporary sibling directory before rename; CLI `--out` and handoff generation write exclusively (`wx`) to `.geloforge-tmp-*` files and roll back on failure, with overwrite refusal on handoff creation.
- **Single-Pass Template Rendering:** Substitutes allowlisted `{{...}}` keys in one pass so user-supplied values containing `{{...}}` cannot trigger secondary placeholder expansion; YAML scalar values are escaped.
- **Zero-Network / Zero-Dependency Tooling:** `core/` and `scripts/` import only Node.js built-ins and make zero network requests (`tests/security.test.mjs` verifies absence of network APIs).
- **Secret Hygiene & Exclusions:** `.gitignore` excludes `.env*`, keys/certs (`*.pem`, `*.key`, `*.p12`, `*.pfx`), `secrets/`, and `local-runtime/`; shared `hasSecretContent` and `isForbiddenSecretPath` filters block credential-like content across context compilation, codebase mapping, and cross-agent handoffs.
- **Non-Destructive Brownfield Adoption & Discovery ([core/adopt-project.mjs](./core/adopt-project.mjs), [core/project-locator.mjs](./core/project-locator.mjs)):** Refuses duplicate adoption, overwriting existing files (including `AGENTS.md`/`GEMINI.md`), symlinks/junctions in target roots or upward discovery ancestors, and traversing out past Git roots into unrelated repos or harness internals; writes exclusively (`wx`) and rolls back only newly created files/empty directories on error.
- **Safe Command-Backed Evidence Capture ([core/evidence-capture.mjs](./core/evidence-capture.mjs)):** Executes only explicit user CLI arguments after `--` with `shell: false` (never commands embedded in tasks, skills, or docs), redacts detected credential/key/bearer/env patterns via `redactSecretContent` before writing `EVID-*.yaml` or printing errors, records timeouts and failures honestly as unverified `draft`, and separates local exit `0` from full correctness. Note: executed commands still run with the invoking user's local OS privileges.
- **Context Compiler Input & Evidence Integrity ([core/context-compiler.mjs](./core/context-compiler.mjs), [core/handoff.mjs](./core/handoff.mjs), [core/project-validator.mjs](./core/project-validator.mjs)):** Blocks oversized (>512 KB source/doc, >256 KB code map) files, binary NUL-byte files, symlinked Second Brain roots/records, unapproved `accepted` ADRs, canonical `is_example: true` fixtures, empty/failed `EVID-*` entries claiming `verified` status, and forged `verified_evidence` inside `HANDOFF-*` records; scopes Git status to project boundaries so parent-repo sibling files do not leak; quarantines `A5`–`A6`/draft records (or omits them via `--exclude-unverified`) and escapes spoofed document delimiters.

### Prompt-Injection Threat Model & Documented-Only Safeguards
- **Prompt-Injection Limitation (Important):** Wrapping files in `<<<GELOFORGE_DOC>>>` delimiters and escaping spoofed fences (`<<<ESCAPED_END_GELOFORGE_DOC>>>`, `<<<ESCAPED_GELOFORGE_DOC`) prevents delimiter-boundary spoofing, **but delimiters alone do NOT prevent adversarial instructions inside untrusted Markdown, external research, or mapped source comments from semantically influencing an AI coding assistant**. Treat delimiters strictly as trust-tier legibility aids, use `--exclude-unverified` when strict isolation is required, and keep human approvals (`APPR-NNNN`) and OS/repository permissions as authoritative controls.
- **Documented-Only Safeguards:** Role-based write ownership (`memory-policy.md`), approval gates (`APPR-NNNN`), max-2 agent concurrency, max-2 retry caps, and zero-spend limits (`token-efficiency.md`) remain **governance policy targets — not enforced by OS ACLs, Git pre-commit hooks, or runtime interceptors**.

## Reporting Security Issues

This repository is released under the [MIT License](./LICENSE). Configure private vulnerability reporting in the GitHub repository security settings. Never commit `.env` files, API tokens, or private keys in issues, pull requests, or commits.
